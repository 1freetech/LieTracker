# LieTracker
Tracking all lies from my conversations with AI.

- [Master ledger](MASTER_LEDGER.md) — cumulative record, counts, evidence and status.
- [Backup ledger](BACKUP_LEDGER.md) — separate full copy of the master.
- [Individual audit runs](incidents/) — dated historical records.

Maintain both cumulative files after every audit. Verify that they match exactly; retain individual audit files and stable incident IDs. Distinguish confirmed mismatches, pending investigations and other defects. Counts cover recorded evidence, not an exhaustive lifetime total. Both copies are in the same public repository; omit sensitive details.
